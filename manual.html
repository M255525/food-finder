🍜 巷口美食通 — 操作手冊

依你所在區域（輸入地址／地標，或選捷運站）與餐期，請 AI 依人數、預算、美食類型或自由文字需求生成一份建議清單。
主要涵蓋台北與新北地區。本工具只需要一把語言模型（AI）的 API 金鑰即可使用，不需要申請 Google 地圖服務、不需要綁信用卡。

📍 本工具目前僅提供台北市與新北市地區的美食推薦服務，其他地區暫不支援。

⚠ 本工具僅供教學、課程及個人使用，禁止未經授權公開發布、販售或商業化使用。

⚠ 建議清單全部由 AI 依其既有知識生成，不是即時查詢的真實資料——店家可能已經歇業、搬遷，地址、電話或距離可能不準確。出發前請務必自行上網搜尋或打電話確認，本工具不對消費結果負責。

⚠ API 金鑰只存在你這台電腦的瀏覽器裡，查詢時會直接連線到你選擇的 AI 服務商，不經過本工具作者或任何第三方伺服器；請勿在共用或公用電腦上填寫金鑰。

快速開始

  1. 按右上角「⚙️」打開設定，選擇一個 AI 服務商，貼上你申請好的 API 金鑰（必填，見下方「申請 API 金鑰」）
  2. 按「儲存設定」
  3. 選餐期、輸入地址或選捷運站、選距離偏好，視需要調整人數／預算／美食類型／自由文字
  4. 按「請 AI 幫我推薦」，稍等幾秒讓 AI 生成建議清單

畫面右上角還有「小／中／大」三個按鈕，可以隨時調整整個頁面的文字大小，設定會記住，下次打開不用重調。

如果按「請 AI 幫我推薦」後出現「AI 服務回應 401」或「金鑰不正確」，最常見原因是金鑰貼錯（多貼到空格或少貼到字元），或該服務商帳號額度已用盡，建議重新複製一次金鑰再貼上。

所在區域怎麼設定

方式說明
🏠 輸入地址／地標直接打入地址、路名或大家熟知的地標名稱（例如「西門町」「市政府」），不需要打得很精確，AI 會依常識判斷這個地區
🚇 選捷運站分兩步驟：先選路線（板南線／淡水信義線／松山新店線／中和新蘆線／文湖線／環狀線／安坑輕軌／淡海輕軌），選好路線後第二個選單才會列出該路線的站別供你選擇，避免 138 個站名一次全部列出來太混亂。同一個轉乘站（例如市政府）在不同路線都選得到

搜尋條件說明

  • 餐期：早餐／午餐／晚餐
  • 距離偏好：300 公尺／500 公尺／1 公里，這是請 AI 盡量在這個範圍內推薦的估計值，不是精確測量的距離
  • 參考人數：AI 會考慮這個人數是否適合聚餐、併桌等情境
  • 預算：平價／中等／高價／不限
  • 美食類型：可複選，不選代表不限
  • 我的需求：自由文字，想吃什麼、不想要什麼、有什麼特殊需求都可以直接打出來，例如「想吃辣的、不要排隊、想找適合聚餐的空間」

AI 如何生成建議

按下「請 AI 幫我推薦」後，本工具會把你設定的所有條件整理成一段文字，送給你選擇的 AI 服務商，請它扮演一位熟悉台北/新北美食的在地朋友來推薦店家。AI 的回答完全依賴它自己既有的知識，不會去查詢任何即時資料（沒有連上 Google 地圖或任何店家資料庫）。

每張建議卡片會顯示店名、類型、大概距離、價位、評價星等（AI 若不確定會直接標示「沒有」，不會亂編數字）、大概位置描述，以及一句推薦理由。卡片最下方都有一個「🔍 上網查證這家店是否還在營業」的連結，按下去會用 Google 搜尋這家店的名稱，強烈建議出發前先點開確認店家還在營業、地址是否正確。

都不滿意怎麼辦？繼續搜尋其他餐飲

如果 AI 給的第一批建議都不滿意，不用重新填一次條件，直接按結果清單最下方的「🔄 都不滿意？繼續搜尋其他餐飲」，AI 會依同樣的條件再想一批不重複的新店家，並標示「第 2 批建議」接在原本清單下方——原本那一批不會消失，你可以從所有已出現過的建議裡挑。可以重複按這個按鈕多次，每按一次就是新的一批。

常見問題

AI 推薦的店家真的存在嗎？

大多數情況下存在，但無法保證。AI 是依訓練時學過的資料回答，資料可能已經過時，店家也可能後來歇業或搬遷。這也是每張卡片都附上「上網查證」連結的原因，請務必養成出發前先確認的習慣。

為什麼每次問同樣的問題，AI 給的答案不太一樣？

這是語言模型的正常特性，同樣的問題每次生成的用詞、順序甚至挑選的店家都可能略有不同，不代表工具故障。

AI 服務回應錯誤怎麼辦？

先確認金鑰有沒有貼對、該服務商帳號額度是否用盡；如果是暫時性錯誤（伺服器忙碌），過幾分鐘再試一次通常就能成功，本工具也會自動重試一次。

文字太小或太大看不清楚？

按頁面右上角的「小／中／大」按鈕即可調整全站文字大小，設定會記住，下次打開這個網站不用重新調整。
