🍜 巷口美食通 — 操作手冊

依你所在區域（目前定位／輸入地址／選捷運站）與餐期，即時查詢 300 公尺／500 公尺／1 公里範圍內的早餐店、咖啡店、餐廳，並依人數、預算、美食類型或自由文字需求給出建議清單。
主要涵蓋台北與新北地區；店家資料來自 Google Places，需自行申請一組 Google Maps API 金鑰才能使用。

⚠ 店家評分／營業時間／價位資料由 Google Places API 即時提供，僅供參考，本工具不保證即時正確，也不對店家實際狀況或消費結果負責，請以店家現場公告與實際狀況為準。

⚠ 若你有設定 AI 服務金鑰，「推薦理由」段落是 AI 依候選店家清單生成的文字，同樣僅供參考，不構成專業建議；AI 也可能理解錯誤或給出不準確的敘述。

⚠ 兩把金鑰（Google Maps、AI 服務）都只存在你這台電腦的瀏覽器 localStorage，查詢時會直接連線到 Google 與你選擇的 AI 服務商，不經過本工具以外的任何伺服器；請勿在共用電腦上填寫金鑰。

快速開始

  1. 按右上角「⚙️」打開設定，貼上你申請好的 Google Maps API 金鑰（必填，見下方「申請 Google Maps API 金鑰」）
  2. 若想使用 AI 理解自由文字需求與產生推薦理由，選擇 AI 服務商並貼上該服務商的 API 金鑰（選填，不填也能正常使用）
  3. 按「儲存設定」
  4. 選餐期、所在區域取得方式、搜尋半徑，視需要調整人數／預算／美食類型／自由文字，按「開始搜尋」

申請 Google Maps API 金鑰

  1. 到 Google Cloud Console 建立一個專案（或使用既有專案）
  2. 在「APIs 與服務」啟用以下兩個 API：Maps JavaScript API 與 Places API (New)
  3. 設定帳單帳戶（Google 提供每月免費使用額度，一般個人查詢用量通常在額度內；實際費用與額度請查 Google Cloud 官方定價頁面，本工具不會經手、也不會向你收取任何費用）
  4. 在「憑證」建立一組 API 金鑰，並建議設定 HTTP referrer 限制（限制只有你使用的網址能呼叫這把金鑰，避免外流被盜用）
  5. 把金鑰貼到本工具的設定面板
如果搜尋時出現「金鑰驗證失敗」或「請求被拒絕」，最常見原因是上面兩個 API 沒有都開通、帳單未設定，或 HTTP referrer 限制沒有涵蓋你目前開啟這個頁面的網址。

所在區域怎麼設定

方式說明
📍 使用目前定位呼叫瀏覽器定位功能，需允許瀏覽器的定位權限；手機與桌機瀏覽器都支援，室內或訊號不佳時可能不準確或失敗
🏠 輸入地址／地標打入任意地址或地標名稱，按「定位」由 Google 轉換成座標；適合已知確切地址時使用
🚇 選捷運站從台北捷運＋新北捷運（環狀線／安坑輕軌／淡海輕軌）共 138 站中選一個，以該站為搜尋中心；站點座標僅供搜尋中心使用，非精確出入口位置

搜尋條件說明

  • 餐期：早餐／午餐／晚餐，會影響預設搜尋的店家類型（例如早餐會一併納入早午餐、烘焙、咖啡類型）
  • 搜尋半徑：300 公尺／500 公尺／1 公里，為 Google Places 的硬性距離限制，不會出現超出範圍的店家
  • 參考人數：目前作為推薦理由的判斷脈絡（例如人數較多時提醒你留意是否可併桌／訂位），Google 沒有「依人數篩選店家」的資料可用
  • 只看目前營業中：勾選後只顯示 Google 判斷目前有營業的店家；此欄位資料同樣可能有缺漏或未即時更新
  • 預算：對應 Google 的價位等級（平價／中等／高價），台灣店家的價位資料常缺漏，未提供價位的店家不會被排除
  • 美食類型：可複選，其中「咖啡店／烘焙／日式／中式」會直接篩選 Google 的店家分類，其餘（火鍋／麵食／西式／素食／小吃）與自由文字需求則用來比對店名與分類
  • 我的需求：自由文字，例如「想吃辣的、不要排隊、想找適合聚餐的空間」；有設定 AI 金鑰時會先讓 AI 理解這段文字，沒有的話會直接拿去做關鍵字比對

AI 功能說明（選用）

設定 AI 服務商與金鑰後，多兩個功能：

  1. 理解自由文字需求：把「我的需求」欄位的自然語言，轉換成幾個具體關鍵字，用來輔助判斷候選店家
  2. 產生推薦理由：從查詢到的候選店家中，挑出最多 5 家最適合的，並各寫一句白話推薦理由，標示「AI 推薦」排在清單最前面

AI 只會從 Google 查到的候選清單裡挑選，不會憑空編造清單以外的店家；若 AI 呼叫失敗（金鑰錯誤、額度用盡、服務暫時異常等），會顯示提示訊息並自動改用一般排序與規則式推薦理由，不影響基本查詢功能。

常見問題

搜尋不到店家怎麼辦？

試著放寬搜尋半徑、拿掉部分美食類型或預算篩選，或換一個位置再搜尋一次；市郊、住宅區或深夜時段附近店家本來就可能較少。

為什麼有些店家沒有評分或價位？

這些欄位由 Google Places 提供，資料完整度取決於店家自己或使用者是否曾在 Google 地圖上填寫，本工具無法補齊缺漏資料，缺漏的欄位也不會用來排除店家。

定位一直失敗？

確認瀏覽器的網站定位權限已允許；室內、地下室或行動網路訊號不佳時定位可能不準或逾時，可改用「輸入地址」或「選捷運站」。
